# GenPark Personal Agent: Somatosensory Jitter Single Fiber EMG (SFEMG) Skill

A pure Python, zero-dependency FastMCP skill for precision neuromuscular transmission evaluation and Single Fiber Electromyography (SFEMG) analysis.

## Features
- **Deterministic Mathematical Models**: Exact formula implementations of Mean Consecutive Difference (MCD) and Mean Sorted Difference (MSD) for firing rate drift compensation.
- **Impulse Blocking Analysis**: Quantifies transmission failures and evaluates safety factor collapse at the motor endplate.
- **Diagnostic Safety Margin**: Automatically grades multi-pair clinical studies into Normal, Borderline, Mild, Moderate, or Severe NMJ defects.
- **Multi-Muscle Database**: Built-in reference boundaries for EDC, Frontalis, Orbicularis Oculi, Biceps, and Tibialis Anterior.

## Installation & Usage

python example_usage.py
